# Olszowiańskie Smaki — strona cateringu

Statyczna strona docelowa promująca lokalny catering z Olszówki. Zawiera jasny, świeży layout, sekcję "Dlaczego my" z wyróżnikami marki, przykładowe menu (pierogi, korytka mięsne, stoły słodkie), ofertę cateringową, rozbudowaną galerię (12 ujęć), slider hero oraz sekcję kontaktu z mapą.

## Podgląd
Otwórz `index.html` w przeglądarce lub uruchom prosty serwer (np. `python -m http.server`) w katalogu projektu. Wszystkie style i skrypty są lokalne.

## Struktura
- `index.html` – treść strony (hero slider, sekcja "Dlaczego my", menu, oferta, opinie, kontakt z mapą, przyciskiem "Zadzwoń" i formularzem mailto)
- `styles.css` – jasny motyw, karty menu, układ galerii, formularz, slider
- `script.js` – obsługa slidera (autoodtwarzanie, przyciski, kropki, pauza po ukryciu karty)
- `assets/logo-olszowianskie-smaki.svg` – znak marki wykorzystywany w nagłówku

## Edycja treści
- Tekst hero i sekcja menu podkreślają domowej roboty pierogi oraz kuchnię zagórzańską w tradycyjnym, polskim stylu
- Dane kontaktowe: tel. +48 793 222 101, e-mail kontakt@olszowianskiesmaki.pl, kuchnia w Olszówce (34-730 Mszana Dolna), ul. Olszówka 176
- Formularz kontaktowy wykorzystuje `mailto` do wysyłki wiadomości, a obok dostępny jest przycisk telefoniczny "Zadzwoń teraz"
- W sekcji "Dlaczego my" podsumowano główne atuty (domowe pierogi, lokalne produkty, szybka organizacja, przejrzyste pakiety)
